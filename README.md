# Simple Todo List
一个轻量级、纯前端实现的待办事项管理工具，无需安装任何依赖，在浏览器中即可直接运行使用。

## 功能特性
- 快速添加待办事项
- 标记事项已完成/未完成
- 删除不需要的待办事项
- 页面样式简洁，操作无学习成本

## 快速使用
1. 下载本项目源码
2. 双击打开 `index.html` 文件
3. 在输入框中输入待办内容，点击添加按钮即可使用

## 运行环境
- 任意现代浏览器（Chrome、Edge、Firefox等）
- 无需后端服务、无需Node.js等环境
